# 🏋️ BMI Calculator

A simple and responsive **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**.

This project calculates a user's BMI based on their height and weight, then displays the corresponding BMI category.

## ✨ Features

* Calculate BMI instantly
* Input validation for invalid or empty values
* Displays BMI rounded to two decimal places
* BMI classification:

  * Underweight
  * Normal Weight
  * Overweight
  * Obese
* Responsive layout
* Modern UI with gradients, hover effects, and animations

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional software or installation is required.
